# Élan Fitness

## 1. Description du projet

Élan Fitness est un site web qui présente une salle de sport à Casablanca. Il permet aux visiteurs de découvrir les activités sportives, les programmes et les services proposés.

Le site contient plusieurs pages : Accueil, À propos, Programmes, Contact et Login.

## 2. Technologies utilisées

- **HTML5 :** structure des pages web.
- **CSS3 :** design, couleurs et mise en page.
- **Git et GitHub :** gestion et partage du code.

## 3. Ce que j'ai compris dans ce projet

Dans ce projet, j'ai appris à :

- Créer des pages web avec HTML.
- Organiser les éléments avec les balises HTML.
- Modifier le design avec CSS.
- Relier plusieurs pages avec des liens.
- Organiser les fichiers du projet.
- Utiliser GitHub pour partager le code.
